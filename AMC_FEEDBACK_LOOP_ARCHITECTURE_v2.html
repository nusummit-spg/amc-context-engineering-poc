AMC Chatbot — Feedback, Evaluation & Self-Correction Architecture

HITL and agentic (no-feedback) evaluation are two entry routes into one pipeline: Feedback → Evaluation → Diagnosis → Controlled Improvement. Every response ends up in the same evidence record, the same tiered evaluation, the same diagnosis step, and the same governed correction path.
